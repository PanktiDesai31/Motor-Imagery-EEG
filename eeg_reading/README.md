- An EEG is interpreted by considering its amplitude, frequency content, spatial distribution across electrodes, and changes over time.
- horizontal band = channel (64 in this case)
- imp part to notice is which frequencies are present in the signal
    Brain waves:
        gamma : 30-100 (Peak concentration, high-level cognition)
        beta : 12-30 (Active thinking, alertness, focus)
        alpha : 8-12 (Relaxed wakefulness, calmness)
        theta : 4-8 (Deep relaxation, creativity, drowsiness)
        delta : 0.5-4 (Deep sleep, healing, unconsciousness)
